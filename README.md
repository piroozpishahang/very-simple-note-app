# Very Simple Note App

A very simple Markdown note-taking app built with **Vue**, **Tauri**, and **TypeScript**.

> ⚠️ This project is experimental and currently under development.

The goal of this project is to experiment with building a simple, native desktop note-taking application using Tauri and Vue.

## Features

* Select a folder for notes
* Create Markdown notes
* Open and edit notes
* Auto-save
* Rename notes
* Delete notes
* Simple desktop UI

## Tech Stack

* Vue
* TypeScript
* Tauri
* Markdown

## Status

This project is **experimental** and should not be considered production-ready.

Features, architecture, and UI may change significantly during development.
